# Agentes

## Arquiteto

Responsável por:

- arquitetura;
- contratos de domínio;
- boundaries;
- decisões estruturais;
- migrations propostas.

## Analista de Regras

Responsável por:

- validar regras de rateio;
- cenários extremos;
- competências;
- liquidação;
- exceções.

## Desenvolvedor

Responsável por:

- implementação;
- testes;
- migrations aprovadas;
- integrações.

## Auditor

Responsável por:

- conferir cálculos;
- validar soma zero;
- revisar permissões;
- testar inconsistências;
- verificar trilha de auditoria.

## Agente de Reconhecimento

Responsável por:

- interpretar comprovantes;
- extrair campos;
- calcular confiança;
- sugerir correspondências.

Nenhum agente de reconhecimento deve confirmar sozinho registros de baixa confiança.
