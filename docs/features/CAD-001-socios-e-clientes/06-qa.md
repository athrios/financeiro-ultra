#### Como abrir o sistema no seu computador (passos 1 a 5)

1. **Prepare o ambiente.** Abra o Docker Desktop e espere ele ficar "em execução". Abra o PowerShell e vá para a pasta do projeto: `cd C:\projetos\financeiro-ultra`.

3. **Crie os dados de teste.** No PowerShell, rode um comando por vez, esperando cada um terminar: `npm run db:start`, depois `npm run db:reset` (apaga os dados de teste antigos e recria os de exemplo: 3 sócios e 4 clientes) e depois `npm run seed:dev` (cria os usuários de teste, todos com a senha do passo 2).
4. **Ligue o sistema.** Rode `npm run build` e, quando terminar, `npm run start`. A janela fica ocupada com o sistema ligado; **não a feche** até o fim do roteiro. Se aparecer erro de porta 3001 ocupada, feche o outro programa que a usa e rode de novo.
